## 4. 过程中的关键决策与变更

### 4.1 MySQL 5.7 → 8.0.46 升级（重要变更）

- **起因**：Django 5.2 连接 MySQL 做版本硬检查，要求 8.0.11+；本机 5.7.21 实测被拒（`NotSupportedError: MySQL 8.0.11 or later is required`）。
- **处置**（经负责人确认旧库无价值）：停用并禁用旧服务 `MySQL57`（数据文件未删除）→ 部署 MySQL 8.0.46 至 `D:\Program Files\MySQL\mysql80` → 初始化数据目录 → 注册新服务 `MySQL80` → 重建 fvil 库与账号。
- **影响**：本机与部署环境完全一致（均 8.0），后续开发无版本顾虑；ORM 保持通用写法（不用 CheckConstraint 等 8.0.16 以下特性）。

### 4.2 网站定位调整（官网 → 业务平台）

- 当前定位为**实验室业务平台**（非官方授权的"官网"），后续争取获得老师/学院授权后可升格官网定位。
- 粗规划 v1.1、细规划 v1.2 已同步更新定位说明与全部表述。

### 4.3 其他

- pip 升级 21.2.3 → 26.2.1（保证后续装包稳定）；
- 超级用户 `fv_admin` 使用随机强密码创建（初始密码见 §8 附录，请及时修改）；
- 管理后台汉化（zh-hans + Asia/Shanghai 时区）。

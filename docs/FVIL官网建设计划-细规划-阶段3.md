## 1. 作业发布与提交

### 1.1 数据模型（doclib app 内）

**`Assignment`（作业）**

| 字段 | 类型/说明 |
|---|---|
| batch | 外键 → Batch（招新批次），作业归属届次 |
| round | 外键 → Round（**自动创建/复用**，round_type=homework，用于批改录分进 Score） |
| title | 作业标题 |
| description | 说明（Text，可空） |
| file | FileField（**PDF 发布文件**，供下载） |
| deadline | 截止时间（DateTime，可空） |
| created_at | 创建时间 |

**`Submission`（作业提交）**

| 字段 | 类型/说明 |
|---|---|
| assignment | 外键 → Assignment |
| student_id | 学号（提交身份，**校验在报名库**） |
| name | 姓名（与学号配对校验） |
| file | FileField（**PDF 报告**，扩展名/类型校验 pdf） |
| submitted_at | 提交时间（auto_now_add） |

约束：**同一作业同一学号仅一份提交**（UniqueConstraint(assignment, student_id)）；重复提交提示，需管理员删除后重交（或放开"覆盖提交"——本阶段按**唯一一份、不可覆盖**做，简单明确）。

### 1.2 提交身份校验（"已在报名库"）

提交表单 = 学号 + 姓名 + PDF 文件。校验逻辑：

```
Applicant.objects.filter(student_id=..., name=...).exists()  → True 才放行
```

- 不匹配 → 表单报错："该学号/姓名不在报名库中，请确认报名信息"；
- 匹配 → 校验通过，提交入库（**提交记录自动关联该 Applicant**，用于批改时直接录分）；
- 无需登录、无需注册（沿用"不做新生注册"决策）。

### 1.3 批改闭环（复用阶段2 成绩系统）

- **发布作业时**：自动创建/复用 `Round`（batch=作业批次，name=作业标题，round_type=homework）并挂到 Assignment；
- **批改流程**：管理员在后台 Submission 列表查看提交（可下载 PDF）→ 录入该轮次成绩（等级 A+~B- + 可选评价，录入人自动记录）——即阶段2 的 Score + 批量录分机制，**零新增开发**；
- **学生查看**：`/recruit/query/`（匿名查询页）自动显示作业成绩（Score 关联 Applicant+Round，查询页已实现）；
- 唯一约束（applicant+round）天然防同一人同一作业重复录分。

### 1.4 在线批阅难度说明（负责人询问）

| 方案 | 含义 | 难度 | 工作量 | 说明 |
|---|---|---|---|---|
| **A 下载批改 + 后台录分** | 批改人下载学生 PDF，本地打开批改，回后台录等级+评价 | **低** | 0 额外开发（复用 Score） | **推荐**；批改质量最高（可逐字批注），仅多一步下载 |
| **B 浏览器预览 + 同页录分** | Admin 定制页内嵌 PDF 预览（浏览器原生 / `<embed>`），旁边录分表单 | **中** | 少（一个定制页 + 预览嵌入） | 免下载，但浏览器内不能写批注 |
| **C 在线批注（红笔/文字留痕）** | PDF 渲染 + 批注层 + 坐标/文本存储 + 回显 | **高** | 大（pdf.js 渲染、批注模型、坐标换算、渲染回显，易碎） | **不建议当前做**；若将来需要，可考虑第三方服务或专用批注工具 |

结论：**本阶段做方案 A**（下载 PDF + 后台录分）。方案 B 作为可选小增强（验收后再定）；方案 C 明确不做。

## 2. 导学材料双形态

| 形态 | 载体 | 维护方式 | 面向用户 |
|---|---|---|---|
| **一：静态站** | `/guide/`（fvil-ec-guide/web，T2-1 已上线） | 维护者改 md → 跑 `tools\build.bat` 重建（不变） | 阅读导学案/作业/附录 |
| **二：文档材料** | `/doclib/`（本阶段新建） | **管理员后台上传**（PDF、代码 zip 等，分类管理） | 下载材料 |

**`Document`（资料文档）**

| 字段 | 类型/说明 |
|---|---|
| title | 标题 |
| category | 分类（choices：导学材料 / 作业文件 / 附录 / 其他） |
| description | 说明（可空） |
| file | FileField（**PDF 或 zip**，白名单校验） |
| uploaded_at | 上传时间（auto_now_add） |
| uploader | 外键 → auth.User（上传人，自动记录） |

- `/doclib/` 列表页：按分类分组展示，标题/说明/大小/上传时间，**点开即下载**（公开，无需登录）；
- 与 `/guide/` 互链：导学资料导航下两个入口并列（静态站 / 材料库），页面内互相提示；
- 材料权限：**资料管理员**（新 Group）可上传/删除；普通用户仅浏览下载。

## 3. 权限

- 建 Group **「资料管理员」**（数据迁移）：doclib 三模型（Assignment/Submission/Document）的增删改查权限；成员由超管分配（可复用招新管理员成员，也可另配——两组成员独立，互不影响）；
- 非该组成员：后台不可见 doclib 管理入口；**前台下载/提交/查询不受限**（公开匿名）；
- 批量录分沿用「招新管理员」组的 Score 权限（作业批改人需同时属于资料管理员或超管——**建议批改人也加入「招新管理员」组**，规划验收时注明）。

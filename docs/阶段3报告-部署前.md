**核心设计决策（验收时确定）**：
1. 作业发布 = **PDF**；提交 = **`report.pdf`（报告）+ `source.zip`（源代码）双击同时提交**，PDF 独立不压入 zip（便于预览）
2. **命名格式校验**：`学号_姓名_report.pdf` / `学号_姓名_source.zip`，与表单学号姓名一致、报告与源代码放反拒绝
3. 提交身份 = 学号 + 姓名，校验「已在报名库」（不注册账号，避免常用密码泄露）
4. 成绩等级制 A+~B- + 可选验收评价；报名不收集意向方向

## 四、当前系统全貌

### 数据模型
- **recruitment**：`Batch`（批次/状态/起止时间）、`Applicant`（姓名/学号唯一/`sid` 学生编号/年级/专业/QQ）、`Round`（轮次）、`Score`（等级+评价，唯一约束 applicant+round）
- **doclib**：`Assignment`（作业/PDF/截止时间，发布自动建作业轮次）、`Submission`（报告+源代码，唯一约束 assignment+student_id）、`Document`（材料库，分类上传）

### 路由与页面
`/`、`/about/`、`/about/teachers/`、`/recruit/`（首页/报名/查询/导出）、`/doclib/`、`/assignments/`（列表/提交）、`/guide/`（静态站）、`/admin/`；导航 7 项

### 权限
「招新管理员」组（16 权限，含录分/导出）、「资料管理员」组（12 权限，材料与作业管理）；作业批改人需在招新管理员组

### 学生工作流
报名（QQ 必填 + 专业下拉）→ 作业下载/提交（截止拦截 + 覆盖写入）→ 成绩查询（等级 + 评价）

### 管理员工作流
发布作业 → 提交列表（未评分在前）→ 新标签页预览报告 → 「录入成绩」（预填）→ 批量下载源代码 ZIP

### 文件存储
- 数据库存 FileField **相对路径字符串**；文件本体在 `D:\HFUT\fvil\media\`（`doclib/assignments/`、`doclib/submissions/report/`、`doclib/submissions/source/`、`doclib/documents/`、`teachers/`）
- 同名上传自动加随机后缀防覆盖；覆盖提交时手动删旧文件（FileField 不自动清理）
- `media/` 已被 git 忽略，**数据 = MySQL 库 fvil + media 目录**，两者部署时都需迁移

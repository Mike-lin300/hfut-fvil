### 1.2 实现方案（临时、静态、不开 app）

1. `config/settings.py` 增加：`GUIDE_ROOT = BASE_DIR / 'fvil-ec-guide' / 'web'`（gitignore 的目录，运行期读盘，不复制）；
2. `config/urls.py` 挂载 `guide/` 前缀：自定义小视图包装 `django.views.static.serve`，空路径默认 `index.html`（文档根 = GUIDE_ROOT；serve 自带 `..` 穿越防护）；
3. 导航栏：base.html 导航加"导学资料"入口（`/guide/`），高亮规则同现有项；
4. 部署（阿里云）：Nginx `location /guide/ { alias <fvil-ec-guide/web/>; }` 直接服务静态站，不进 Django；或保留 Django serve 兜底（站小，无性能顾虑）。**不复制、不双份维护**：web 产物由 `tools\build.bat` 重建，平台侧实时读盘。

## 2. 招新系统数据模型（4 张表，承接细规划 v1.5 §5.1）

| 模型 | 字段 | 约束/说明 |
|---|---|---|
| `Batch`（招新批次） | 名称（如"2026秋招"）、报名开始/截止时间、状态（未开始/报名中/培训中/考核中/已结束） | 每年一届，数据按批次隔离；状态自动拦截报名（已确认） |
| `Applicant`（报名者） | 姓名、**学号**、年级、专业、联系方式、批次(外键)、报名时间、状态（已报名/培训中/通过/淘汰/候补）、备注 | 学号唯一；**不收集意向方向**（已确认）；**不注册账号** |
| `Round`（考核轮次） | 批次(外键)、名称（如"第一轮培训"）、类型（培训/考核/作业）、日期、说明 | 一届可多轮 |
| `Score`（成绩） | 报名者(外键)、轮次(外键)、**等级**（A+/A/A-/B+/B/B-，choices）、评价(TextField 可空，验收人员文本)、录入人、录入时间 | **唯一约束**：同一报名者同一轮次仅一条成绩 |

> 迁移策略：新建 `recruitment` app；一次性建 4 张表（T2-2）。

## 3. 权限与行为设计（承接 v1.5 §5.2/5.3）

- 管理组 **Group「招新管理员」**（成员≤20 人，由超级管理员分配）→ 可管理批次/报名者/轮次、**录入成绩（等级+可选评价）**、导出；
- 报名者：**无账号不登录**；匿名查询页（学号+姓名）→ 本人各轮次**等级** + 可选**验收评价**；
- 报名拦截：Batch 状态非"报名中"时报名页拒绝提交并提示；
- 数据导出：负责人可下载全量名单/成绩（Excel，openpyxl）；
- 规模适配：200 人报名表单只含必填项；Admin 列表筛选（批次/状态/专业）；成绩录入按轮次筛选、支持批量勾选录入。
